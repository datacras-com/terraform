Pre-work: Mühitin Quraşdırılması DPE-07

Terraform + GitHub Copilot Modulu · Dərsdən əvvəl tamamlanmalıdır · ~45–60 dəqiqə

Bu təlimatı 1-ci dərsdən əvvəl tamamlayın. Dərsdə quraşdırmaya vaxt ayırmayacağıq — yalnız 15 dəqiqəlik yoxlama olacaq. Hər addımın sonunda yoxlama əmri var: əmr işləyirsə, addım tamamdır. Problem yaranarsa, dərsdən əvvəl müəllimə yazın.
1

GitHub Account + Copilot

~10 dəq
  1. github.com/signup — account-unuz yoxdursa, yaradın.
  2. github.com/features/copilot səhifəsinə keçin və Copilot Free planını aktivləşdirin (ayda 2000 code completion + 50 chat mesajı — kurs üçün kifayətdir).
  3. Yoxlama: github.com/settings/copilot səhifəsində Copilot statusu aktiv görünməlidir.
💡 Tələbəsinizsə: GitHub Education-a universitet e-poçtu ilə müraciət edin — Copilot Pro pulsuz verilir (limitsiz completion). Təsdiq bir neçə gün çəkə bilər, ona görə indi başlayın.
2

VS Code + Extension-lar

~10 dəq
  1. code.visualstudio.com/download — öz əməliyyat sisteminiz üçün endirin və quraşdırın.
  2. VS Code-u açın → sol paneldə Extensions (⇧⌘X / Ctrl+Shift+X) → HashiCorp Terraform extension-unu quraşdırın (sintaksis rəngləmə, autocomplete).
  3. Copilot barədə: yeni VS Code versiyalarında GitHub Copilot və Copilot Chat daxili (Built-in) gəlir — ayrıca quraşdırmaq lazım deyil (extension səhifəsində Install əvəzinə "Disable AI Features" görünür). Köhnə VS Code-dursa, GitHub Copilot extension-unu quraşdırın (Chat onunla birgə gəlir) — yalnız rəsmi olanı: naşir github.com təsdiqli olmalıdır.
  4. Sağ aşağı küncdə Copilot ikonuna klik → Sign in to GitHub → brauzerdə təsdiqləyin.
✅ Yoxlama: istənilən faylda // hello world funksiyası yazın — Copilot boz rəngdə kod təklif etməlidir. Təklifi Tab ilə qəbul edirsiniz.
3

Terraform

~10 dəq

macOSHomebrew ilə

brew tap hashicorp/tap
brew install hashicorp/tap/terraform

LinuxUbuntu / Debian

wget -O - https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install terraform

Windowswinget ilə (PowerShell)

winget install Hashicorp.Terraform

Alternativ: developer.hashicorp.com/terraform/install səhifəsindən ZIP endirib PATH-a əlavə edin.

✅ Yoxlama (yeni terminal pəncərəsində): 
terraform version
# Terraform v1.x.x çıxmalıdır
4

AWS Account

~15 dəq
  1. aws.amazon.com/free — yeni account yaradın (kredit kartı tələb olunur, amma kurs boyu xərc çıxmayacaq). Qeydiyyatda Free plan seçin.
  2. Region olaraq eu-north-1 (Stockholm) istifadə edəcəyik — konsolda sağ yuxarıdan seçin.

IAM istifadəçisi (Terraform üçün)

  1. AWS Console → IAM → Users → Create user → ad: terraform-student
  2. Attach policies directly → AdministratorAccess seçin (yalnız şəxsi tədris account-u üçün məqbuldur!)
  3. Yaradılan istifadəçiyə keçin → Security credentials → Create access key → Command Line Interface (CLI) → key-ləri təhlükəsiz yerdə saxlayın (bir dəfə göstərilir!)

Budget alert (MƏCBURİDİR)

  1. Console → Billing and Cost Management → Budgets → Create budget
  2. Zero spend budget template-ini seçin → e-poçtunuzu yazın → yaradın.
⚠️ Bu addımı ötürməyin! Budget alert unudulmuş resurs pula çevrilməmişdən əvvəl sizə e-poçt göndərir. Kursun sonunda hər şeyi terraform destroy ilə siləcəyik — bu, kursun rəsmi ritualıdır.

AWS CLI

# macOS
brew install awscli
# Ubuntu/Debian
sudo apt install awscli
# Windows (PowerShell)
winget install Amazon.AWSCLI
aws configure
# AWS Access Key ID:     [IAM-dən aldığınız key]

✅ Yoxlama: 
aws sts get-caller-identity
# Account nömrəniz və terraform-student istifadəçisi görünməlidir
